# Google ADK – AI Agent Development 🤖

A hands-on learning project exploring **Google Agent Development Kit (ADK)**, Python, and Gemini to build AI-powered agents.

## 🚀 What I'm Learning

- Building AI agents using Google ADK.
- Working with Gemini models.
- Writing agent instructions and prompts.
- Defining agent roles and safety boundaries.
- Exploring tools, sessions, and multi-agent systems.

## 🛠️ Tech Stack

- Python
- Google ADK
- Google Gemini API

## ⚙️ Getting Started

```bash
git clone https://github.com/Ajinkyaw15/google-adk-first-agent.git
cd google-adk-first-agent

python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt
```

Configure your Gemini API key in a `.env` file:

```env
GOOGLE_GENAI_USE_VERTEXAI=FALSE
GOOGLE_API_KEY=your_api_key
```

Run the project:

```bash
adk web
```
